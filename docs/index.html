What this first version can do

FileAvailable in V1
PDFView pages, navigate and save a copy
TXT / CSVEdit UTF-8 text, replace words and save a copy
DOCX / XLSXText previews; convert to TXT for edits. Office formatting is not retained in TXT.
PhotosImport an image to PDF; basic camera preview capture

Not a full Word/Excel editor. No PDF text editing, OCR, formula calculation or multi-page scanning yet. Read-aloud supports text previews, not PDF/scanned text. Prefer importing a full-size camera photo for clear scans.

A little help getting started

How do I install it?

Download the APK on your Android phone and open it. Android may ask you to allow installation from your browser. Install the preview only if you trust this publisher. It is not a Play Store release.

Does it need paid AI?

No. Common commands run locally. The repository also includes an optional rule-based Python service designed for Lightning's free CPU. No Lightning endpoint is preconfigured or deployed with this download.

What happens to my documents?

Documents stay on your phone. Optional backend use sends only command text after confirmation. Android's speech provider may process your voice online. The app has no advertising or analytics.

Which commands can I try?

“Next page” · “page 2” · “padho” · “save” · “replace Suresh with Ramesh” · “Suresh ki jagah Ramesh likho”. You can always use the buttons or type instead.
