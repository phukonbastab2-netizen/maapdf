A little help getting started

How do I install it?

Download the APK on your Android phone and open it. Android may ask you to allow installation from your browser. Install the preview only if you trust this publisher. It is not a Play Store release.

Does it need paid AI?

No. The 27 PDF tools and common commands run locally. The repository also includes an optional rule-based Python intent service designed for Lightning's free CPU. No Lightning endpoint is preconfigured or deployed with this download.

What happens to my documents?

Documents stay on your phone. Optional backend use sends only command text after confirmation. Android's speech provider may process your voice online. The app has no advertising or analytics.

Which commands can I try?

“Next page” · “page 2” · “padho” · “save” · “replace Suresh with Ramesh” · “Suresh ki jagah Ramesh likho”. You can always use the buttons or type instead.
