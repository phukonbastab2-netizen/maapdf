# Maa mascot

Created with the built-in image-generation tool, then copied into `app/src/main/res/drawable-nodpi/maa.png` and `docs/maa.png`.

Final prompt:

> Use case: illustration-story. Create a polished original 2D cartoon mom mascot for the Android document assistant maapdf. A friendly middle-aged Indian mother, warm expressive face, kind brown eyes, small bindi, dark hair in a bun with a few silver strands, simple sari, tasteful round glasses. Waist-up caricature with gently oversized head, one hand raised in a welcoming wave and the other holding a single plain paper. Contemporary hand-drawn animation aesthetic, clean confident outlines, softly shaded flat colors, warm cream, terracotta and muted green palette. Front-facing clear silhouette, centered with generous transparent margins, genuinely transparent background. One character only. No text, no letters, no logos, no watermark. This is a reusable app mascot asset, not a UI screenshot.

The app animates this 2D illustration with gentle sway and vertical movement. It is not a rigged character, lip-sync animation, or frame-by-frame hand wave. Tap the character to pause or resume. Android's system animator-disable setting is respected.
