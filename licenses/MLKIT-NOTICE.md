# Google ML Kit and translation attribution

OCR and translation use Google ML Kit. Models run on the device. Input images/text and outputs are not sent to Google for processing. The SDK may contact Google for model updates and compatibility information and sends performance/utilization metrics.

- SDK terms and privacy: https://developers.google.com/ml-kit/terms
- Translation usage guidance: https://developers.google.com/ml-kit/language/translation/translation-terms
- Attribution requirements and full translation disclaimer: https://cloud.google.com/translate/attribution
- Google Translate / Cloud Translation: https://cloud.google.com/translate

The official `color-regular@2x.png` attribution badge was downloaded from Google's linked badge archive, copied unchanged to `res/drawable-nodpi/google_translate.png`, and displayed beside translation results. The action button is labelled “Translate with Google”. maapdf is not affiliated with or endorsed by Google.

Translations are automatic. Google provides no warranties for accuracy, reliability, merchantability, fitness for a particular purpose or noninfringement. Review the original document for important decisions.
